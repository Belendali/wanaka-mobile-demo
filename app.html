刷、玩、造、存

按照 Figma 1022 区块做的可点击 Demo。
  1. 00首次进入：欢迎页 → 选喜欢的类型 → Home 上 3 步提示（上滑 / 点一下 / 黑猫）。第一次发送时才要求登录
  2. 01Home：Explore / Following / Friends / Remix。Remix 点视频直接玩，点底部输入框带着这个游戏去 Create
  3. 02Create：✦ 写一个点子，↻ 换一个；黑猫开关是 Plan mode，先出计划再 Build it
  4. 03Chat：Thinking → Building（可以离开）→ 完成，“Thought for” 可展开；+ 可加照片 / 3D / 游戏里的素材。输入 online 可看失败状态
  5. 04Publish：15 秒预览视频，Wana 自动录或自己录，可左右滑对比
  6. 05Chats 一个列表 + 筛选；Me 里点游戏进 Project（Game / Assets / Chat），Assets 可 Swap；铃铛 = 通知，齿轮 = 设置
视频为示意素材；生成过程为模拟。网址加 #intro 可重看引导。
